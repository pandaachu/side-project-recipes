# Notion 資料同步命令

同步 Notion 資料庫的最新內容到本地快取或檢查資料結構。

## 執行步驟

1. **檢查 Notion API 連線**
   - 確認環境變數 `NOTION_API_KEY` 已設定
   - 測試 API 連線是否正常

2. **取得資料庫結構**
   - 讀取 Portfolio Database 的 schema
   - 列出所有欄位名稱和型別

3. **驗證資料一致性**
   - 比對程式碼中的型別定義與實際 Notion 欄位
   - 報告任何不匹配的欄位

4. **顯示摘要**
   - 顯示資料庫中的項目數量
   - 列出最近更新的項目

## 注意事項

- 不要修改 Notion 資料庫的實際內容
- 若發現型別不匹配，只報告但不自動修正
- 輸出結果使用繁體中文

## 參數

$ARGUMENTS

如果提供 "full" 參數，則執行完整的資料同步並更新 `@types/notion.d.ts` 型別定義。
