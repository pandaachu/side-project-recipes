# 設計審查

根據 taikisato.com 的設計風格審查元件或頁面。

## 審查標準

### 1. 極簡美學 (Minimalism)

- [ ] 是否避免過度裝飾？
- [ ] 色彩是否簡潔（黑白灰 + 單一強調色）？
- [ ] 是否有足夠的留白？

### 2. 排版 (Typography)

- [ ] 字體大小是否有清晰的層級？
- [ ] 行距是否舒適（1.5-1.75）？
- [ ] 文字對齊是否一致？

### 3. 間距 (Spacing)

- [ ] 區塊間距是否足夠（py-24 以上）？
- [ ] 元素間距是否使用一致的 scale？
- [ ] 是否避免過度擁擠？

### 4. 動畫 (Animation)

- [ ] 動畫是否微妙且有目的？
- [ ] 是否使用 AOS 或 Framer Motion？
- [ ] 動畫時長是否適當（200-500ms）？

### 5. 響應式 (Responsive)

- [ ] 在手機上是否可讀？
- [ ] 是否使用 Mobile-first 設計？
- [ ] 斷點轉換是否平滑？

## 輸出格式

```
🎨 設計審查報告 - [元件名稱]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 總評分: 8/10

✅ 優點:
  • 留白處理得當
  • 動畫效果微妙

⚠️ 改進建議:
  • 建議增加區塊間距
  • 可考慮添加 hover 效果

📝 具體修改:
  1. 將 py-16 改為 py-24
  2. 添加 transition-opacity duration-300
```

## 參數

$ARGUMENTS

請提供要審查的元件路徑或頁面名稱，例如：
- `@components/sections/About.tsx`
- `首頁`
- `projects/[slug] 頁面`
